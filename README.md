# 서울자유여행 (Seoul Free Trip)

서울에 오기 전에 여행을 미리 체험해 보는 3D 서울 여행 게임이에요.
A 3D walking game for simulating a trip to Seoul before you come.

## 플레이하기
GitHub Pages가 켜져 있으면 저장소의 Pages 링크에서 바로 플레이할 수 있어요.

## 내 컴퓨터에서 실행하기
`index.html`을 더블클릭하면 지도 데이터를 불러오지 못해요. 이 폴더에서 아래 명령으로 간단한 서버를 켠 뒤 http://localhost:8000 을 여세요.

```
python3 -m http.server 8000
```
